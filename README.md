# FrightWorks PR media

Screenshots shown in pull requests and issues of [FrightWorks](https://github.com/FrightWorks/FrightWorks-no100f).
GitHub has no API for its own attachments, so tools put images here and link them.

- Files go in `pr/<number>/` or `issue/<number>/`.
- Screenshots only: no disc images, game files, textures, saves, logs or recordings.
- Check a picture before pushing it: no personal paths, names or addresses on screen, and no metadata beyond colour and resolution.
- Files that a PR or issue links to must stay here, or the picture breaks.
